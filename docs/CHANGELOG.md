# Версия 2.0 — 2026-10-01

Последние изменения выполнены для адаптации материалов к использованию в качестве учебных пособий по алгоритмам анализа данных, машинного обучения и искусственного интеллекта, с переносимым запуском в Windows и Linux.

Код адаптирован с **Python 3.7 на Python 3.12**. Опорная и проверенная среда — Python 3.12; совместимость с Python 3.7 больше не заявляется. Правильное обозначение выпуска — **2.0**.

## Четыре учебные ошибки

По пояснению автора, перечисленные ошибки намеренно оставлялись в материалах, предоставлявшихся студентам, чтобы студенты находили их во время работы. Это авторское пояснение назначения задания, а не вывод из анализа истории Git.

1. **Основы PyTorch:** оптимизатор в опыте с `ourNet2` получал параметры прежней `ourNet`. Теперь он создаётся для конкретной обучаемой сети; проверяется изменение её параметров.
2. **Классификация изображений:** название ошибочно описывало детекцию, хотя сеть классифицировала целый кадр. Порядок PIL width/height был перепутан и затем маскировался reshape. Название задачи исправлено, историческое имя файла сохранено; подготовка теперь даёт `(N, height, width, channels)` без искажающего reshape.
3. **Перенос стиля:** конкатенация списков признаков двух стилей приводила к тому, что zip использовал только первый. Теперь для каждого слоя рассчитаны оба style loss с независимыми весами.
4. **Классификация текстов:** названия авторов и порядок текстов расходились. Теперь manifest — единый источник имени, файла и номера класса.

## Дополнительно

- Сохранены идеи исходных моделей: Dense/CNN, обычный автоэнкодер, VAE, VGG19 style transfer, Bag of Words/Embedding и Seq2Seq LSTM. Короткий режим уменьшает вычисления, не подменяя алгоритмы трансформерами или внешними AI API.
- Обновлены Input shapes, learning_rate, `.keras`/`.weights.h5`, TextVectorization, VGG19 weights API, Pillow resampling, torch tensors и inference_mode.
- Случайные значения задаются seed; устройство и источники данных выбираются явно.
- Train/validation/test отделены; словарь учится только на train; документы делятся до нарезки на окна. В классификаторе не продолжается прежняя модель при заявлении независимого опыта.
- В VAE учитывается фактический размер последнего batch; исправлено описание набора FashionMNIST.
- В анализе заёмщиков удалена посторонняя ячейка с неопределённым df; Pipeline, imputer и scaler обучаются только на train; добавлены ROC-AUC/PR-AUC и отчёты по классам.
- Убраны Colab-only imports, личные пути Google Drive, shell wget/unzip и неподтверждённое требование 90% accuracy.
- Добавлены офлайн demo, учебные задания, три профиля зависимостей, исполняемые проверки и CI для Windows/Linux.
- Удалены устаревшие выводы ноутбуков; результаты новых проверок сохраняются отдельно и не выдаются за прежние показатели.
