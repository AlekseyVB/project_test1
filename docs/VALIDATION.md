## Что проверяют 10 unit-тестов

- Корень репозитория находится из вложенной папки.
- Width/height не перепутаны: не квадратное изображение сохраняет правильную форму и расположение пикселей.
- Синтетический набор воспроизводится при одинаковом seed.
- Окна текста не выходят за границы и параметры проверяются.
- Имя автора соответствует номеру класса из одного manifest.
- Документы не пересекаются между train/validation/test.
- Неправильные значения переключателей отклоняются.
- Локальный MNIST читается без сетевой загрузки и без pickle.
- Загрузка не выполняется без явного разрешения.
- Схема, версия и Python-синтаксис всех ноутбуков корректны; нет Colab-only путей и прежних outputs.

В выполненных PyTorch-ячейках дополнительно проверяется изменение параметров конкретной обучаемой сети; в style transfer рассчитаны оба style loss и проверено отсутствие градиентов у VGG; в VAE проверен неполный batch.

## Границы результата

- Это **короткий синтетический запуск**, не доказательство качества на MNIST, FashionMNIST, реальных текстах, изображениях или финансовых CSV.
- Demo для style transfer использует случайные VGG weights: проверяется механика двух style loss, не художественное качество.
- Полное обучение, реальная точность, GPU, внешние загрузки и VS Code на другой машине не проверены.
- GitHub Actions для Windows/Linux настроен; его актуальный результат проверяется отдельно во вкладке Actions. Этот документ фиксирует локальные результаты. Отдельный GitLab CI не настроен.
- Seed не обещает побитово одинаковый результат между ОС и вычислительными backend.
- В глубоко вложенном Windows-пути установка TensorFlow сначала не прошла из-за длины имени файла; короткое временное окружение решило проблему без изменения системных настроек.

Для воспроизведения используйте команды из `docs/ENVIRONMENTS.md`. После публикации требуется отдельно проверить удалённый CI, а для оценки моделей — запуск на реальных данных с независимым test.
