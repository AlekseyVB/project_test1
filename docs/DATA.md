# Источники и формат данных версии 2.0

Все ноутбуки по умолчанию работают на **синтетических демонстрационных данных**. Это позволяет изучать ход алгоритма без личных файлов автора, сети и GPU. Такие примеры не доказывают точность на реальных данных и не заменяют полноценный эксперимент.

Данные в репозиторий не включаются. Путь задаётся `MLLAB_DATA_DIR`; по умолчанию — `data` в корне проекта. Файлы читаются с UTF-8. Выбирайте `MLLAB_DATA_SOURCE=local` или `builtin` явно. Загрузка разрешена только при `MLLAB_ALLOW_DOWNLOAD=1`.

| Урок | Реальный источник / структура | Ограничения |
|---|---|---|
| Классификация изображений | `local`: `data/images/<класс>/*.jpg` или PNG | Минимум два класса, достаточно изображений для stratified train/validation/test. Если кадры одного видео связаны, до использования урока разделяйте их по исходным видео, а не случайно по кадрам. |
| Автокодировщик MNIST | `builtin`: `data/mnist.npz`, ключи `x_train`, `x_test` | При разрешённой загрузке используется официальный Keras URL и SHA-256. Локальные данные читаются с `allow_pickle=False`. |
| VAE FashionMNIST | `builtin`: формат torchvision FashionMNIST в `data/FashionMNIST` | Загрузка только по явному флагу. Сохранено именно FashionMNIST из исходного кода, несмотря на историческое имя файла. |
| Перенос стилей | `local`: `data/style/content.jpg`, `style1.jpg`, `style2.jpg` | Нужны предобученные VGG19 weights: либо ранее закэшированные, либо явное разрешение загрузки. Кэш в `.cache/torch`. В demo веса случайные: проверяется механика, не качество переноса. |
| Классификация текстов | `local`: `data/authors.json` и отдельные UTF-8 документы | Минимум три независимых документа на автора. Разбивка по документам идёт до создания окон. Для локальных текстов при QUICK=0 длина окна 1500, шаг 200; короткие документы требуют уменьшения настроек окна. |
| Seq2Seq | `local`: `data/pairs.json` | Минимум 10 непустых пар. Train/validation/test отделены до создания словаря. |
| Анализ заёмщиков | `local`: `data/training_data.csv` и `test_data.csv` | Числовые признаки, одинаковая схема, известная непустая целевая колонка `SeriousDlqin2yrs`. Это не инструмент принятия кредитных решений. Личные данные и отдельные строки не сохраняются в отчёт. |
| Основы Keras / PyTorch | Данные создаются в памяти | Внешние датасеты не нужны. |

## Manifest авторов

```json
{
  "Булгаков": ["writers/bulgakov_1.txt", "writers/bulgakov_2.txt", "writers/bulgakov_3.txt"],
  "О. Генри": ["writers/henry_1.txt", "writers/henry_2.txt", "writers/henry_3.txt"]
}
```

Класс, имя автора и путь связаны одной записью manifest. Нельзя указывать один файл дважды или выходить относительным путём за пределы каталога данных. Используйте тексты, на которые у вас есть права. Фрагменты одной книги нельзя считать независимыми, если они попадут одновременно в обучение и тест.

## Пары для Seq2Seq

```json
[
  {"question": "Как работает градиент?", "answer": "Он показывает направление изменения функции."},
  {"question": "Что такое эпоха?", "answer": "Один проход по обучающему набору."}
]
```

Это только пример схемы: для выполнения нужны минимум десять записей.

## Источники встроенных датасетов

- MNIST: https://keras.io/api/datasets/mnist/ ; источник загрузки и контрольная сумма взяты из Keras 3.15.1.
- FashionMNIST: https://docs.pytorch.org/vision/stable/generated/torchvision.datasets.FashionMNIST.html .
- VGG19: https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.vgg19.html .

До использования сторонних наборов проверьте лицензию и права. Никакие архивы, исполняемые программы, pickle или сторонний код автоматически не скачиваются и не запускаются.
